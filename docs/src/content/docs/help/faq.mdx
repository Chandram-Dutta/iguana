## The basics

### What is Iguana?

A tiling window manager for macOS. It arranges the windows on each desktop so they fill the
screen without overlapping, and lets you move between them and rearrange them from the
keyboard. See [Why Iguana](/start/why-iguana/).

### What is the difference between a desktop and a Space?

None. "Space" is Apple's name for a desktop. These docs say "desktop". Two commands, `space`
and `move-to-space`, use Apple's word.

### Does Iguana need System Integrity Protection turned off?

No. It needs the Accessibility permission and nothing else.
[Under the hood](/help/under-the-hood/#why-sip-is-not-needed) explains why.

### Which versions of macOS does it run on?

macOS 14 or later. Sending a window to another desktop is quickest on recent macOS, where
Iguana can use the system's own route. It has been tested on macOS 27.2.

### How do I install it?

Download the disk image and drag Iguana into Applications, or build it from source with
`scripts/bundle.sh`. See [Install](/start/install/).

### How do I update it?

With `brew upgrade --cask iguana`, or by downloading the new disk image. Iguana tells you in
its menu when a newer version is out, and leaves the updating to you. See
[Staying up to date](/start/install/#staying-up-to-date).

### Does Iguana connect to the internet?

For one thing only: about once a day it asks GitHub whether a newer version has been
released. The request carries nothing about you or your Mac, and nothing is downloaded. To
switch it off, turn off **Check for updates** in the General pane of the settings window, or
set `check = false` under `[updates]` in the config file.
[The one network request](/help/under-the-hood/#the-one-network-request) lists exactly what
is sent.

## Everyday use

### What happens to my windows when I quit Iguana?

Nothing. Every window stays exactly where you see it. Iguana never hides or parks a window,
so there is nothing to put back. The same is true if Iguana crashes.

### Do my layouts survive a restart?

A restart of Iguana, yes, together with the windows you floated or tiled by hand and the
minimum window sizes Iguana has learned. A restart of the Mac, mostly: as your apps reopen their
windows, each desktop takes its saved layout again. Iguana recognises the windows by their
app and title, and by where they were. This works for the first three minutes after tiling
starts. Windows it does not recognise are tiled as new windows. See
[Limitations](/help/limitations/#limits-of-the-current-design).

### Why did my shortcut do nothing?

Most often because there was nothing for the command to act on. With one window on the
desktop there is no neighbour to focus, move past or resize against. Run `iguana status` and
read the last line. See
[Troubleshooting](/help/troubleshooting/#shortcuts-appear-to-do-nothing).

### Can I still use Mission Control, gestures and the system's desktop shortcuts?

Yes. Iguana tiles whichever desktop macOS is showing, however you got there.

### Can I switch desktops without the slide animation?

Not with Iguana alone. The switch is done by macOS. Turning on Reduce Motion in System
Settings shortens the slide to a fade.

### Can I send a window to another desktop without going there?

Yes. Use `move-to-space N --stay`. See
[Customising shortcuts](/guides/shortcuts/#send-a-window-away-without-following-it).

### Can an app always open on the same desktop?

Yes. Give it a rule with a `desktop`, in the config file or in the Window Rules pane of
the settings window. A window that opens is sent there and you stay where you are. See
[Open an app's windows on a desktop](/guides/desktops-and-displays/#open-an-apps-windows-on-a-desktop).

### Can an app always open on the same display?

Yes. Give it a rule with a `display`: part of the display's name, or its number from the
left. A window that opens is moved there, onto the desktop that display is showing. See
[Open an app's windows on a display](/guides/desktops-and-displays/#open-an-apps-windows-on-a-display).

### Do rules move the windows that are already open?

Not by themselves. A rule sends a window to its desktop or display when the window opens.
Run `iguana apply-rules` to do the same for every window that is open now. See
[`apply-rules`](/reference/commands/#apply-rules).

### How do I move a window to another display?

Press <kbd>option</kbd>+<kbd>shift</kbd>+<kbd>.</kbd> to take it to the next display, or
<kbd>option</kbd>+<kbd>shift</kbd>+<kbd>,</kbd> for the previous one. The focus goes with it.
`move-to-display 2` takes it to display 2. You can also `move` it past the edge of its layout,
or drag it there. <kbd>option</kbd>+<kbd>.</kbd> and <kbd>option</kbd>+<kbd>,</kbd> move just
the focus. See
[Desktops and displays](/guides/desktops-and-displays/#move-the-focus-and-windows-between-displays).

### How do I make one window fill the desktop for a while?

Press <kbd>option</kbd>+<kbd>f</kbd> to zoom it, and again to put it back.

### How do I stop Iguana tiling one window?

Focus it and press <kbd>option</kbd>+<kbd>shift</kbd>+<kbd>space</kbd>. To always float an app,
add a [rule](/guides/floating-windows/#rules).

### How do I stop Iguana tiling everything for a moment?

Choose **Pause Tiling** from the menu bar item, or run `iguana pause`.

### Can Iguana draw a border around the focused window?

Yes, and it needs no second tool. Switch on **Ring around the focused window** in the Layout
pane of the settings window, or set `enabled = true` under
[`[focus-ring]`](/reference/configuration/#focus-ring). The ring is drawn outside the window,
in your accent colour or one you choose.

### Can I resize and rearrange with the mouse?

Yes. Drag an edge to resize, and the layout keeps the new proportions. Drag a window by its
title bar onto another tile: the middle swaps the two, an edge takes that half of the tile. An
outline shows where the window will land. See
[Moving and resizing with the mouse](/guides/how-tiling-works/#moving-and-resizing-with-the-mouse).

### Can the focus follow the pointer?

Yes. Switch on **Focus follows pointer** in the Layout pane of the settings window, or set
[`focus-follows-mouse = true`](/reference/configuration/#focus-follows-mouse) under
`[layout]`. The window the pointer comes to rest on gets the focus without a click. The
keyboard still has the last word: a shortcut that moves the focus is not undone by a pointer
that lies on another window.

## Behaviour

### Why is one window larger than its share?

It has a minimum size and refused to get smaller. Iguana gives it the room it insists on and
fits the others around it. See
[Windows that will not shrink](/guides/how-tiling-works/#windows-that-will-not-shrink).

### Does it work with Stage Manager?

Yes. Windows in other stages keep their slot and take no room, and Iguana can leave room for
the strip of recent apps. See
[Stage Manager, fullscreen and tabs](/guides/stage-manager-fullscreen-tabs/).

### What about native fullscreen?

Iguana leaves fullscreen windows and fullscreen Spaces alone.

### Does it have stacking, an accordion layout or a scratchpad?

Stacking, yes: `stack` makes the windows of a group overlap, with a strip of each one left in
view, which is what other window managers call an accordion. See
[How tiling works](/guides/how-tiling-works/#stack). There is no scratchpad, because Iguana
never hides a window. Instead, [`focus-app`](/reference/commands/#focus-app) brings an app
forward with one key, or opens it. See
[Customising shortcuts](/guides/shortcuts/#bring-an-app-forward-or-open-it) and
[Limitations](/help/limitations/).

### Why do some apps stutter when windows animate?

Each frame of the animation asks the app to really resize its window. Heavy apps redraw
slowly. Shorten the duration or turn animation off. See [Animation](/guides/animation/).

## Configuration

### Do I need a config file?

No. Without one, the built-in defaults apply. `iguana config init` writes a file you can edit.

### Where is the config file?

`~/.config/iguana/iguana.toml`, or under `$XDG_CONFIG_HOME` if that is set.
`iguana config path` prints it.

### Do I have to restart Iguana after editing the config?

No. The file is reloaded when you save it.

### What if I make a mistake in the config file?

Iguana keeps running. A syntax error is reported with its line and the previous settings
stay. A smaller problem is a warning and only that setting falls back to its default. See
[Configuration](/reference/configuration/#when-the-file-has-a-mistake).

### Is the settings window a separate set of settings?

No. It edits the same file, one value at a time, and keeps your comments and formatting. See
[The settings window](/guides/settings-window/).

### Can I script Iguana?

Yes. Every command can be sent from a terminal: `iguana focus left`, `iguana tree`, and so on.
With `--window`, a command acts on a window other than the focused one:
`iguana close --window 1402`. See [Command line](/reference/command-line/).

A script can also read what Iguana knows as JSON (`iguana list-windows --json`) and be run by
Iguana when something changes: the desktop, the focus, a window opening or closing, the layout,
or the pause. See [Status bars and scripts](/guides/status-bars-and-scripts/).
