This page lists every built-in shortcut. They apply when there is no config file, and each
one stays in force until your config file changes it or switches it off.

<kbd>option</kbd> is Option (⌥), <kbd>ctrl</kbd> is Control (⌃), <kbd>shift</kbd> is
Shift (⇧) and <kbd>cmd</kbd> is Command (⌘).

The direction keys follow the convention of the Vi editor: <kbd>h</kbd> is left,
<kbd>j</kbd> is down, <kbd>k</kbd> is up and <kbd>l</kbd> is right.

## Focus

| Keys | Written as | Command |
| --- | --- | --- |
| <kbd>option</kbd>+<kbd>h</kbd> | `option-h` | `focus left` |
| <kbd>option</kbd>+<kbd>j</kbd> | `option-j` | `focus down` |
| <kbd>option</kbd>+<kbd>k</kbd> | `option-k` | `focus up` |
| <kbd>option</kbd>+<kbd>l</kbd> | `option-l` | `focus right` |

## Move the window

At the edge of the layout, `move` continues onto the next display.

| Keys | Written as | Command |
| --- | --- | --- |
| <kbd>option</kbd>+<kbd>shift</kbd>+<kbd>h</kbd> | `option-shift-h` | `move left` |
| <kbd>option</kbd>+<kbd>shift</kbd>+<kbd>j</kbd> | `option-shift-j` | `move down` |
| <kbd>option</kbd>+<kbd>shift</kbd>+<kbd>k</kbd> | `option-shift-k` | `move up` |
| <kbd>option</kbd>+<kbd>shift</kbd>+<kbd>l</kbd> | `option-shift-l` | `move right` |

## Size and shape

| Keys | Written as | Command | What it does |
| --- | --- | --- | --- |
| <kbd>option</kbd>+<kbd>minus</kbd> | `option-minus` | `resize shrink` | Shrink the window. |
| <kbd>option</kbd>+<kbd>equal</kbd> | `option-equal` | `resize grow` | Grow the window. |
| <kbd>option</kbd>+<kbd>slash</kbd> | `option-slash` | `flip` | Flip the container between side-by-side and top-to-bottom. |
| <kbd>option</kbd>+<kbd>s</kbd> | `option-s` | `stack` | Stack the windows of the container so that they overlap, or make them tiles again. |
| <kbd>option</kbd>+<kbd>f</kbd> | `option-f` | `zoom` | Make the window fill the desktop, or put it back. |
| <kbd>option</kbd>+<kbd>shift</kbd>+<kbd>space</kbd> | `option-shift-space` | `float` | Float the window, or tile it again. |
| <kbd>option</kbd>+<kbd>shift</kbd>+<kbd>b</kbd> | `option-shift-b` | `balance` | Give every window an equal share. |

<kbd>minus</kbd> is the <kbd>-</kbd> key, <kbd>equal</kbd> is the <kbd>=</kbd> key and
<kbd>slash</kbd> is the <kbd>/</kbd> key.

## Undo

These take back changes to the layout of the desktop you are on, drags with the mouse
included. [Undo](/guides/how-tiling-works/#undo) has the details.

| Keys | Written as | Command | What it does |
| --- | --- | --- | --- |
| <kbd>option</kbd>+<kbd>z</kbd> | `option-z` | `undo` | Take back the last change to the layout. |
| <kbd>option</kbd>+<kbd>shift</kbd>+<kbd>z</kbd> | `option-shift-z` | `redo` | Make the change you took back again. |

## Commands with no default shortcut

These commands exist but are not bound to keys: `close`, `pause`, `reload`, `quit`, and
`resize` with `width` or `height`. [Customising shortcuts](/guides/shortcuts/) shows how to bind them.

## With the mouse

While you drag a tiled window by its title bar, an outline shows where it lands if you let
go. [Moving and resizing with the mouse](/guides/how-tiling-works/#moving-and-resizing-with-the-mouse)
has the details.

- Drop it on the middle of another tile to swap the two.
- Drop it near an edge of another tile to take that half of the tile. The other window keeps
  the rest.
- Drop it on the middle of a stack to add it to the stack, or near an edge of the stack to put
  it beside the stack.
- Drop it anywhere else and it goes back to its tile.
- Drag the edge of a tiled window to resize it. The layout keeps the new proportions.
